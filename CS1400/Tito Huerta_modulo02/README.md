# 🧪 Módulo 2: Ejercicios de Entrada y Salida en Python

## 📘 Instrucciones para los Estudiantes

Este módulo incluye **tres ejercicios** diseñados para ayudarte a practicar el uso de `input()` y `print()` en Python. 

Podrás:
- Escribir programas simples que procesen datos ingresados por el usuario.
- Verificar tus soluciones utilizando pruebas automatizadas en Python.

---

## ✅ ¿Qué debes hacer?

### 1. Abre cada ejercicio 1 por 1

En cada carpeta hay uno o dos archivos. En los siguientes hay TODO's que completar.
Los ejercicios independientes son:
- `saludo.py`: Saludo simple solo para asegurar que funciona y probar un f string.
- `codigo2.py`: Suma de dos números
- `temp.py`: Conversión de temperatura

Para cada ejercicio:
1. Abre el archivo de código correspondiente (`.py`).
2. Lee atentamente los comentarios e instrucciones dentro del código.
3. Escribe tu solución y guarda los cambios (`Ctrl + S` o `Cmd + S`).

### 2. Test codigo2.py: Prueba tu código con el autotesters

1. Abre el archivo de prueba correspondiente en la misma carpeta (`test_codigo2.py`).
2. Mira el contenido, pero no lo cambies.
3. Ejecuta el archivo en VS Code:
   - Abre la terminal desde el menú superior: `Terminal > New Terminal` (o `View > Terminal`).
   - Escribe el comando correspondiente y presiona *Enter*:
     * Para Windows: `python test_codigo2.py`
     * Para Mac/Linux: `python3 test_codigo2.py`
4. Si tu solución es correcta, verás un mensaje verde de éxito (✅). Si falla, lee el mensaje de error para corregir tu código.
