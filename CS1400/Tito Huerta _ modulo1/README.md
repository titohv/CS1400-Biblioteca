- Actividad de reto
Abre un nuevo documento, ponle un nombre y que termine con .py
Luego imprime escribir una palabra a la terminal de esta manera.  
por ejemplo: 
print("  __       __          ")
print("/    \    /  \  ___  | _    ___  ____")
print("\     \/\/   / / _ \ | _ \ / _ \ \   ")
print(" \ __  /\ __/  |___  |_ _/ \___   \ ")

- Entrega
La entrega de este primer proyecto sera por medio de capturas de pantalla. Debe incluir tu nombre hasta arriba de cada archivo.


- Consejos para programar
Usa #comentarios junto a cada print() para explicar lo que estás mostrando.
Nombra tus variables de forma descriptiva.
Evita nombres como x1, x2 o n3; prefiere nombres como total_alumnos, promedio_tiempo, etc.
Guarda tus archivos en un nuevo cartapacio, algo asi 'meganM1' para diferenciar entre
el que descargaste para luego comprimirlo y submitir el correcto.
